# Politique de sécurité — Modey

Les problèmes de sécurité et les bugs sensibles (exploits, contournements d'authentification, fuites de données) doivent être signalés **de manière privée** afin de ne pas exposer les utilisateurs.

## Comment signaler

- Utilisez la [page de signalement privé de vulnérabilité](https://github.com/Modey-NewWorld/modey-launcher/security/advisories/new) (visible uniquement par les mainteneurs).
- Ou contactez directement : contact@flowcrea.fr

## Ce qui est considéré comme sensible

- Contournement de l'authentification Yggdrasil / SSO
- Élévation de privilèges (Fondateur / Admin / Modérateur)
- Exécution de code arbitraire dans le launcher
- Fuite de jetons, clés ou données personnelles

## Délai de réponse

Nous visons une réponse initiale sous 7 jours et un correctif sous 30 jours pour les problèmes critiques.

Merci de ne pas divulguer publiquement avant correction.
